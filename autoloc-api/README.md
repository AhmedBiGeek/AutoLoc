# AutoLoc

## Project Overview

AutoLoc is a multi-agency vehicle rental management platform.

## Project Objectives

The platform aims to manage vehicle rental operations across multiple agencies and provide the necessary functionality for the different actors involved in the rental process.

## Actors

- Client
- Agent d'agence
- Responsable d'agence / Manager
- Administrateur

## Technologies

- Java 17+
- Spring Boot
- Maven
- MySQL
- Git / GitHub
- Postman
